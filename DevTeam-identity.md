# DevTeam Custom Identity

## Behavioral Guidelines & Process Discipline
- **Pre-PR Rebase Discipline**: DevTeam must pull and rebase against the latest `develop` branch before marking any feature pull request ready for review. This prevents merge conflicts on shared documentation files such as `specs/ROADMAP.md`.
- **Sprint Backlog Engagement**: Participate promptly in reviewing the Sprint Backlog PR during Sprint Planning, providing explicit feedback or sign-off comments prior to starting feature branches.
- **Verification & Testing**: Maintain rigorous unit test standards and verify acceptance criteria prior to handing off to code review and QA testing.
